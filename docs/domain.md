# 港澳科普巡展路由领域约定

服务采用事件时间与接收时间分离的记录方式（事件信封中的 `occurredAt` 与 `recordedAt`）。所有业务身份由调用方提供的稳定标识表示，审计记录不得以覆盖方式修改。

## 记录模型

- 全部状态变更以追加式事件写入 `events.jsonl`，状态只能由事件重放重建；幂等记录本身也是事件（`CommandRecorded`），重启后重复请求仍被识别。
- 每条事件携带 `entities` 索引，时间线查询按实体（含 `school:<学校id>`）过滤，呈现每次改派的原因（`reason`）、责任方（`responsibility`）与受影响学校（`affectedSchoolIds`）。

## 核心不变量

- 同一资源在同一时间窗口只能被一把未过期锁持有；锁的 fencing 号单调递增，释放需出示令牌，重复释放是幂等空操作。
- 批准路线是原子操作：任一资源冲突则整体失败；仅当持有方路线优先级更低且尚未出发时允许抢占，抢占产生 `LockPreempted` / `RoutePreempted` 记录。
- 展具损坏后状态为 `damaged` 并退出排期；受影响活动只能经由"替代方案 → 显式接受"恢复或改期，系统不做静默改期。
- 节假日与跨日规则按场馆各自时区的本地日期判定，窗口按半开区间 `[start, end)` 计算。
- 维护停用窗口与路线占用窗口冲突时拒绝排期；已批准路线执行中不可取消，只能走事故流程。

## 责任方取值

`carrier`（承运方）、`venue`（场馆方）、`operations`（运营方）、`unknown`（待认定）。
